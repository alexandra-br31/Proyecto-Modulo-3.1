# OrderFast - Gestión de Pedidos

Proyecto web base realizado con HTML, CSS y JavaScript.

## Archivos
- index.html: estructura de las pantallas.
- styles.css: diseño y paleta de colores.
- script.js: inicio de sesión, registro y navegación básica.

## Paleta utilizada
- Bistro: #210100
- Goldfinch: #E6A341
- Butter: #FECE79
- Indian Red: #B1A436
- Garnet: #8C0902

## Cómo probarlo
1. Abre la carpeta en Visual Studio Code.
2. Abre `index.html` en el navegador.
3. Puedes crear una cuenta desde "Crear una cuenta".
4. También existe una cuenta de demostración:
   Usuario: admin
   Contraseña: 123456

## Importante
Este es un prototipo de interfaz. Los usuarios se guardan únicamente en `localStorage` del navegador. Para el proyecto final, se puede conectar con PHP y MySQL para cumplir con el almacenamiento real de datos.
